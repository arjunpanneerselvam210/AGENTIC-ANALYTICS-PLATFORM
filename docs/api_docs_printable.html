1. Architectural Overview

FreshMart Agentic Analytics provides secure, AI-powered natural-language analytics for FreshMart enterprise business data across retail operations, customer relationship management (CRM), human resources (HRMS), inventory warehousing, purchasing, and financial performance.

Core Engineering Principles

  • Decoupled Dual-Database Architecture: High-volume business transactional data resides in MySQL (company_analytics), strictly segregated from authentication credentials, user records, and RBAC rules stored in PostgreSQL (company_auth).
  • Controlled Database Interfacing via MCP: AI agents never execute arbitrary SQL strings directly on connection pools. All database schema inspection and analytical queries are mediated through a read-only Model Context Protocol (MCP) tool provider with strict AST validation, 1000-row bounds, and query timeouts.
  • Backend-Authoritative RBAC: User identity and permissions are verified by PostgreSQL JWT before natural-language parsing or query synthesis occurs. Inquiries targeting unauthorized domains are rejected with 403 Forbidden at the API barrier.
  • LangGraph Multi-Agent Collaboration: Specialized agent nodes collaborate sequentially to classify intent, check permissions, inspect schemas, generate read-only SQL, validate queries, plan diagnostic investigations, and synthesize grounded responses.

4. Agentic Analytics API

POST /api/v1/analytics/query

Summary: Run Natural-Language Business Analytics Query

Operation ID: runNaturalLanguageAnalyticsQuery

Accepts a natural-language business question and executes it through the LangGraph multi-agent pipeline.

Multi-Agent Pipeline Stages:

  1. Request Validator: Checks input question bounds (1–2000 characters).
  2. Intent Classifier: Classifies domain (Sales, Finance, Inventory, HR, CRM), operation (AGGREGATION, COMPARISON, ROOT_CAUSE), and target tables.
  3. Permission Checker: Evaluates user RBAC codes against target domains. Rejects unauthorized requests with 403 Forbidden.
  4. Schema Planner: Calls MCP tool describe_table to dynamically retrieve columns and constraints.
  5. SQL Generator: Qwen 2.5-Coder synthesizes precision read-only SQL.
  6. SQL Security Validator: AST parser verifies query is read-only (SELECT only; blocks INSERT, UPDATE, DELETE, DROP, ALTER, TRUNCATE, OUTFILE).
  7. SQL Executor: Executes validated SQL strictly through MCP with safety row limits.
  8. Root-Cause & Investigation Planner: Formulates diagnostic hypotheses and computes factor variance.
  9. Business Analyzer & Response Generator: Llama 3.1 synthesizes grounded executive answers with data provenance citations.

Request Schema (AnalyticsQueryRequest):

FieldTypeRequiredDescription
questionstringYesNatural-language business analytics question (1-2000 characters)
conversation_idstringNoOptional session ID for contextual conversational continuity

Pre-configured OpenAPI Examples:

  • Sales Trend: {"question": "Show monthly sales trend for the last 12 months."}
  • Inventory Alert: {"question": "Which products are currently low in stock?"}
  • Cross-Domain: {"question": "Which products generated the highest revenue and are currently low in stock?"}
  • Root-Cause Analysis: {"question": "Why did profit decrease in August?"}
  • Workforce Comp: {"question": "Show average employee salary by department."}

5. Executive Dashboard & Telemetry APIs

GET /api/v1/analytics/dashboard

Summary: Get Executive Dashboard KPIs & Sales Velocity Trends

Operation ID: getExecutiveDashboardMetrics

Returns deterministic, real-time executive dashboard metrics queried directly from FreshMart MySQL.

Query Parameters: range (string, enum: today, 7d, 30d, 90d, 12m, default: 12m)

Response Structure (DashboardResponse):

  • kpis: Top-line cards (Total Revenue: ₹14.82Cr, Customers: 1,250, Orders: 14,820, Active Employees: 500).
  • sales_trend: 12-month historical monthly revenue and order volumes.
  • category_distribution: Sales distribution by category (Fresh Produce, Dairy & Eggs, Snacks, etc.).
  • top_products: High-velocity SKUs with active warehouse balances.
  • insights: Live telemetry alerts (inventory reorder warnings, August profit anomaly).
GET /api/v1/analytics/insights

Summary: Get Enterprise Insights, Anomalies & Strategic Recommendations

Operation ID: getEnterpriseInsightsAndAnomalies

Returns structured, grounded insights and detected statistical anomalies calculated from ledger telemetry.

Response Structure (EnterpriseInsightsResponse):

  • insights: Enterprise cards with headline metric, percentage variance, evidence table, and recommendation.
  • anomalies: Statistical outlier records (e.g. August 2026 Emergency Shipping Expense departing +381.4% from baseline).

Python Integration Example

import requests

BASE_URL = "http://localhost:8000/api/v1"

# 1. Authenticate
login_resp = requests.post(f"{BASE_URL}/auth/login", json={
    "username": "ceo",
    "password": "CeoPassword123!"
})
token = login_resp.json()["access_token"]
headers = {"Authorization": f"Bearer {token}"}

# 2. Run Natural-Language Analytics Query
query_resp = requests.post(
    f"{BASE_URL}/analytics/query",
    headers=headers,
    json={"question": "Why did profit decrease in August?"}
)
result = query_resp.json()

print(f"Question: {result['question']}")
print(f"Answer:   {result['answer']}")
print(f"Factors:  {len(result.get('root_cause_analysis', {}).get('factors', []))} causal factors identified")
